# Microsoft Foundry Agent Service Demos

Simple examples of building and using agents with Microsoft Foundry.

| Demo | C# | Python |
| --- | --- | --- |
| [Prompt agent](prompt-agent/README.md) | [Available](prompt-agent/csharp/README.md) | [Work in Progress](prompt-agent/python/README.md) |

The prompt-agent demo creates an agent and asks two related questions in the same conversation.

Running the demos requires an Azure subscription, a Foundry project, a deployed model, and appropriate access permissions. Model usage can incur Azure charges.
